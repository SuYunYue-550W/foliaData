# HarmonyOS NEXT 真机调试与发布：证书操作指南

适用范围：本工程的 `harmony/folia/`（ArkWeb 壳 + Capacitor 自定义平台桥）。
当前状态：**已能用 Command Line Tools 26.0.1 编译出 HAP，但未签名**，因此装不上真机。
本文只讲怎么把「未签名 HAP」变成「能装到真机的签名 HAP」，不重复编译步骤（见 `harmony/README.md` 第四节）。

---

## 0. 先搞清楚三样东西

| 名称 | 后缀 | 作用 | 谁生成 |
|---|---|---|---|
| 密钥库（含私钥） | `.p12` | 证明「你是你」，签名时用它做私钥 | 你在 DevEco Studio 里生成，一次生成长期用 |
| 证书请求 | `.csr` | 拿去华为换正式证书的中间文件 | 由 `.p12` 导出，DevEco 自动做 |
| 调试/发布证书 | `.cer` | 华为签发的公钥证书 | 华为开发者后台签发，有效期通常 1 年 |
| 调试 Profile | `.p7b` | 授权「哪台设备 + 哪个应用 + 哪些权限」 | 华为开发者后台生成，绑定设备 UDID |
| 发布 Profile | `.p7b` | 上架用，不绑定设备 | 华为开发者后台生成 |

**关键区别**：
- **调试证书 + 调试 Profile** → 装到你登记过 UDID 的真机，用来验证功能（**你现在应该走这条**）。
- **发布证书 + 发布 Profile** → 上架华为应用市场，或者做不限制设备的正式发布。

一个容易踩的坑：`.p7b` 里写死了 `bundleName`，必须与 `AppScope/app.json5` 里的
`"bundleName": "top.izuna.foliamajor.harmony"` **完全一致**，否则签名过了也装不上。

## 1. 前置条件（缺一不可）

1. **华为开发者账号**，且已完成**实名认证**（个人账号即可做真机调试；上架应用市场另需相应资质）。
   注册地址：`https://developer.huawei.com/consumer/cn/`
2. **一台 HarmonyOS NEXT 真机**，能拿到 UDID（下面第 3 节讲怎么取）。
3. **DevEco Studio**（建议 5.x，匹配本机 Command Line Tools 26.0.1）。
   自动签名最简单；如果你想全程命令行，可以只在 DevEco 里生成一次材料，之后用 hvigorw 构建。
4. 本工程的 bundleName 已固定为 `top.izuna.foliamajor.harmony`——**申请 Profile 时填这个**，不要改工程里的。

## 2. 推荐路线：DevEco 自动签名（最省事，强烈建议先走这条）

这条路 DevEco 会**自动**帮你生成 `.p12`、申请 `.cer`、查设备 UDID、生成 `.p7b`，并写进工程配置。

### 步骤

1. **打开工程**：DevEco Studio → `File > Open` → 选 `harmony/folia/`。
   ⚠️ 已知坑：hvigor **拒绝中文路径**。本仓库在中文路径下，DevEco 里打开前请先把
   `harmony/folia` 复制到纯 ASCII 路径（例如 `D:\folia-harmony-sign`），
   签好名、出完包再把 HAP 拷回来。

2. **登录华为账号**：DevEco 右上角头像 → 登录开发者账号（实名认证过的那个）。

3. **自动签名**：`File > Project Structure > Project > Signing Configs` →
   勾选 **Automatically generate signature**。
   DevEco 会依次：生成 `.p12` → 生成 `.csr` → 向华为申请 `.cer` → 生成 `.p7b` →
   把三个文件路径写进 `build-profile.json5`。
   如果提示选择设备，用数据线连上真机并开启「开发者模式 + USB 调试」。

4. **确认产物**：DevEco 会在 `build-profile.json5` 顶层 `app.signingConfigs` 写入一段，
   里面含 `material.storePassword`、`material.certpath`、`material.profil` 等字段。
   `default.signingConfig` 会指向它。

5. **构建签名包**：`Build > Build Hap(s)/APP(s) > Build Hap(s)`。
   产物在 `entry/build/default/outputs/default/entry-default-signed.hap`（文件名可能略有差异，
   认准 `signed` 字样，未签名的是 `unsigned`）。

6. **装到真机**：
   - DevEco 里直接点运行（会自动装），或
   - 命令行：`hdc install entry/build/default/outputs/default/entry-default-signed.hap`

> 自动签名的 `.p7b` 有效期通常是 **90 天或 1 年**（看华为当前策略），过期后重做第 3 步即可，
> `.p12` 私钥不用重新生成。

## 3. 手动路线：自己收集 UDID / 证书 / Profile（适合 CI 或无 DevEco 环境）

### 3.1 取真机 UDID

```bash
# 真机开「开发者选项 > USB 调试」，连上电脑
hdc list targets          # 列出设备
hdc shell bm get --udid   # 输出 64 位 UDID
```
`hdc` 在 HarmonyOS SDK 的 `toolchains` 目录里（本机：`D:\folia-harmony-sdk\command-line-tools\toolchains`）。

### 3.2 生成密钥库和证书请求

```bash
keytool -genkeypair -alias folia -keyalg RSA -keysize 2048 \
  -validity 3650 -keystore folia.p12 -storetype PKCS12 \
  -storepass <你自己的密码> -keypass <你自己的密码> \
  -dname "CN=Folia, OU=FoliaData, O=FoliaData, L=Wuhan, ST=Hubei, C=CN"

keytool -certreq -alias folia -keystore folia.p12 \
  -storetype PKCS12 -storepass <你自己的密码> -file folia.csr
```

### 3.3 在华为开发者后台申请证书和 Profile

1. 进入 `AppGallery Connect > 用户与权限 > 证书管理` → 上传 `folia.csr` → 下载 `folia.cer`。
2. `AppGallery Connect > 用户与权限 > 设备.registration` → 登记第 3.1 步拿到的 UDID。
3. `AppGallery Connect > HarmonyOS 应用 > 创建应用` → package 名填 `top.izuna.foliamajor.harmony`。
4. `证书管理 / Profile` → 创建 **调试 Profile** → 绑定刚建的 `.cer` 和登记过的设备 → 下载 `folia_debug.p7b`。

### 3.4 配进工程

在 `build-profile.json5` 的 `app` 下加：

```json5
"signingConfigs": [
  {
    "name": "default",
    "type": "HarmonyOS",
    "material": {
      "storePassword": "<密码的十六进制，见下>",
      "certpath": "D:/folia-certs/folia.cer",
      "keyAlias": "folia",
      "keyPassword": "<同上十六进制>",
      "profile": "D:/folia-certs/folia_debug.p7b",
      "signAlg": "SHA256withECDSA",
      "storeFile": "D:/folia-certs/folia.p12"
    }
  }
],
"products": [
  {
    "name": "default",
    "signingConfig": "default",
    // ... 其它原有字段保持不变
  }
]
```

**密码要转成十六进制**：DevEco 自动签名时会写好；手动填的话，
`storePassword` / `keyPassword` 要写十六进制串（例如明文 `123456` → `313233343536`）。
可以用 `echo -n '你的密码' | xxd -p` 得到。

> 注意：本工程的 `build-profile.json5` 目前刻意**不含** `signingConfigs`（测试里也钉住了这一点），
> 因为之前没有证书。你按上面加进去之后，那条测试断言会失败——这是预期的，
> 到时候告诉我，我把测试改成「允许存在签名配置」。

### 3.5 命令行出签名包

```bash
cd D:\folia-harmony-build        # ASCII 路径
# 环境变量按之前的构建方式设置（NODE_HOME / DEVECO_SDK_HOME / JAVA_HOME / PATH）
hvigorw assembleHap --mode module -p product=default --no-daemon
```
产物 `entry-default-signed.hap` 即可安装。

## 4. 装好之后重点验证什么

签名包装上真机后，按这个顺序验（都是本轮新写但**只有编译期证明**的能力）：

1. **启动不白屏、不卡 logo**：主界面出来，能看到底部导航。
2. **原生播放**：放一首本地歌 → 锁屏 → 通知栏应能播放/暂停/上下首（这是 `AVPlayer` + `AVSession`）。
3. **在线音乐**：搜一首在线歌 → 能出结果即为原生 HTTP 转发（`FoliaNative.httpRequest`）绕过了 CORS。
   这一条最关键——如果还报 `Failed to fetch`，说明桥没被前端启用，要回来看 pluginHeaders。
4. **Apple Music 登录**：设置 → 账号 → Apple Music → 登录。
   预期：宿主 Web 页面**此时才**出现（平时不该弹），能完成 Apple 登录。
5. **壁纸入口**：设置里壁纸相关入口应该**不显示**（鸿蒙无系统悬浮窗，如实降级）。
6. **错误提示**：启动时不应再有模组错误（Windows 上刚修的那个路径 bug 与鸿蒙无关，但顺带看看）。

把上面每条的实际现象告诉我，我按结果修。

## 5. 常见坑

| 现象 | 原因 | 处理 |
|---|---|---|
| 签名成功但装不上，报 `INSTALL_FAILED` bundleName 不匹配 | Profile 里写的包名不是 `top.izuna.foliamajor.harmony` | 回开发者后台重建 Profile |
| 提示设备未授权 | UDID 没登记，或 `.p7b` 不是调试型 | 登记 UDID，重新生成调试 Profile |
| `hvigor` 报中文路径错误 00306003 | 工程在中文目录 | 复制到 ASCII 路径构建 |
| DevEco 自动签名失败，提示网络错误 | 华为开发者站点需要稳定网络 | 重试；或走手动路线上传 `.csr` |
| 证书过期后装不上 | `.cer` / `.p7b` 有有效期 | 重做自动签名或申请新证书 |
| 上架被拒 | 权限声明、隐私政策、软著等合规材料不全 | 与代码无关，按 AGC 反馈补材料 |
