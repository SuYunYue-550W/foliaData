## 三、新功能详解

### 1. 伴唱模式（播放页「控制」页签）

三档开关：关 / 伴奏（人声消除）/ 人声独唱。实现是 Web Audio 的**中/侧信号实时路由**（侧信号=伴奏，中信号+150Hz 高通=人声），切换在增益上走斜坡，**不重播、不卡顿**。为什么不用 htdemucs 分轨：那条管线只分离每首歌头尾各 30 秒（为过渡手势准备），撑不起整首歌的伴唱。安卓原生播放（ExoPlayer）不走 Web Audio 图，该端灰置并提示。

### 2. 年度听歌报告（听歌档案页）

「生成回顾报告」→ 全屏浮层：总时长/次数、Top 10 歌曲/歌手/专辑、热力峰值时段、每周柱状图、与上周期对比；一键导出 1080×1920 竖版分享图（canvas 绘制 PNG）。

### 3. 本地智能电台（播放列表页签 📻 按钮 / 命令面板搜「电台」）

以当前歌为种子，优先级：听歌档案里相关的常听曲目 > 同专辑 > 同歌手 > 兜底随机，共 20 首无缝续到当前队列后面。选曲纯函数可测，每次乱序（电台不该每次一样）。两个入口走同一个 `startSeedRadio` runner，行为永远一致。

### 4. 一起听（Jam 房间）

播放页面板 + 设置弹窗「一起听」：主机建房得 6 位短码，客机输入加入。主机广播播放/暂停/切歌/队列，客机跟随（进度按事件时间戳外推，1 秒精度）；断线重连以全量快照对齐；客机本地操作不回环（手动切歌自动跳回并提示「跟随房主中」）。房主离房或心跳超时 → 房间解散（简单可靠，不做转交）。**需要自建 sync server**（面板里有部署指引）。

### 5. AutoEQ 耳机校正导入（调音台均衡页「导入 AutoEQ」）

粘贴 AutoEq 生成的 ParametricEQ.txt / 结果 CSV / 图形 EQ 数值，自动对数域插值拟合到本项目十段 EQ，preamp 处理有说明；解析预览 + 行级报错。纯前端逻辑，手机端同样可用。

### 6. 本地曲库标签写回 + 模板重命名（实体菜单「写回文件标签」）

桌面端专属。支持 mp3（ID3v2.4）/ FLAC / OGG / M4A 标签写回（标题/艺术家/专辑/专辑艺术家/音轨/年份），**写前自动备份**；同对话框支持 `{title}/{artist}/{album}/{track}/{year}` 模板批量重命名，冲突自动编号。执行前预览旧值→新值，失败逐文件报告。

### 7. 桌宠联动扩展（设置 → 通用 → 鲸鱼桌宠）

| 联动 | 行为 | 默认 |
|---|---|---|
| 鼓点起舞 | 跟随 beatFx 节拍脉冲缩放（不打断舞步、零解码开销；智能动感模式未开时安静待着） | 开 |
| 歌词气泡 | 当前句歌词变化时气泡显示（截断 20 字符），仍受「动作气泡」总开关约束 | 开 |
| 久坐提醒 | 连续听歌累计 45 分钟气泡提醒休息，可调 15–120 分钟，暂停不重置 | 开 |

## 五、本次新增：窄屏 `bravais-seam` 布局折叠

### 背景

`bravais-seam` 是「图书馆（library）」套件的缝布局引擎——屏幕侧边那条可展开的信息带（完整信息条 / 书脊 / 海报 / 面板）。原逻辑已有响应式：

- 视口 ≥ 900px：默认完整信息条（`full`）
- 视口 480–899px：默认书脊（`spine`，64px 窄条）
- 视口 < 480px（手机竖屏）：**原来仍是书脊**

在竖屏手机上，书脊虽然窄，但仍会压住一部分墙面的交互区；更关键的是，完整信息条（300px）和歌手海报（≥520px）在极窄屏一旦被展开就会溢出视口。因此新增**手机竖屏断点**：默认直接折叠为隐藏（仅留屏幕侧边的悬浮标签），把整面墙让出来；手机上即使用户手动展开，也只给书脊，不再展开成放不下的形态。

### 改动文件

| 文件 | 改动 |
|---|---|
| `src/library/suites/bravais/bravaisConstants.ts` | 新增常量 `BRAVAIS_PHONE_VIEWPORT_PX = 480` |
| `src/library/suites/bravais/bravaisSeamLevel.ts` | `defaultSeamLevel` 在手机宽返回 `'hidden'`；新增 `isPhoneViewport` / `defaultSeamRestoreLevel`；`resolveSeamLevelOnResize` 与 `resolveSeamEscapeLevel` 处理手机档的跨阈值折叠与「Esc 退回书脊」 |
| `test/unit/library/bravais/bravaisSeamLevel.test.ts` | 新增 3 个手机折叠单测（断点默认值、跨阈值折叠/展开、Esc 退回、store 行为） |

### 行为对照

| 视口宽度 | 缝默认等级 | 手动展开后 |
|---|---|---|
| ≥ 900px | full（完整信息条） | — |
| 480–899px | spine（书脊） | full |
| < 480px（手机竖屏） | hidden（仅悬浮标签） | spine（书脊） |

> 断点仅对竖屏手机生效；横屏手机走自动横向缝，不进此档。`syncViewport` 已在 `BravaisStage.tsx` 随舞台宽度实时调用，折叠断点自动生效，无需额外接线。

## 七、前版变更（保留记录）

### 0. 播放页右侧面板：点空白处收起

播放页那个四页签面板（封面 / 控制 / 播放列表 / 音质）是**浮在页面右上角的**，没有遮罩层 —— 它压住歌词和封面时，以前只能去右下角摸那颗小小的圆形手柄才能收起，手机上尤其难按。本版改成：**点面板以外的任意空白处即收起。**

实现要点（`src/components/panelTab/shell/PanelShell.tsx`）：

| 细节 | 做法 | 为什么 |
|---|---|---|
| 事件 | 监听 `pointerdown` 而非 `click` | 从面板里往外拖结束时也会派发 `click`，用 `click` 会误收起 |
| 阶段 | `document` 捕获阶段 | 播放页内部有大量 `stopPropagation`，冒泡阶段收不到 |
| 命中判定 | 整个面板外壳（含手柄）算"里面" | 手柄自己已有开关逻辑；若把外壳排除在外，点手柄会触发两次（关→开），等于没反应 |
| 白名单 | 跳过 `[role="dialog"]`、`[data-folia-float-layer]` | 面板上方可能再叠设置窗、右键菜单、Toast 等浮层，点这些不该把面板一起关掉 |
| 生命周期 | 只在面板展开时挂监听 | 收起状态零开销，也不影响其他页面 |

### 1. 删掉启动时的「测试版」提示框

原来每次启动都会弹一个窗口，说「这个包是从 dev 分支构建的……别拿它当日常使用的主版本」。本版整块移除：`TestBuildNotice.tsx`、`buildChannel.ts`、`AppSurface.tsx` 解除挂载、i18n 的 `testBuild` 整块、对应单测。帮助页「版本」行的 `Unofficial build` 标记**保留**（仅在复制进 issue 时起作用，不弹窗）。

### 2. 帮助页新增「音频效果器」分组

帮助页补上「音频效果器 · 六页签的处理链」入口卡片、分组四行说明、右下「打开音频效果器」按钮（先收设置窗、等 180ms 再开控制台，避免两层浮层叠加），以及两端差异说明。新增 i18n 键 11 个 × 3 语言（`help.audioEffects*`）。

### 3. 沉浸音效接入的接线修复（重要）

沉浸音效接入时，`playbackGraph` 把子图的 `input` 与 `output` 都传成了同一个音量节点 —— 子图的干声通路于是绕过音量，**音量滑杆压不住它**。修法：子图内部新增汇集点 `mix`，`playbackGraph` 改为 `效果链 → immersiveIn → 子图 → immersiveOut → 音量`。新增单测钉住这条接线。

### 4. 沉浸音效（双端）

调音台新增第六页「沉浸」，七项处理在 **桌面端（Web Audio）与手机端（ExoPlayer 原生 DSP）各实现一遍**：虚拟环绕、交叉馈送、人声增强、夜间模式、黑胶模拟、8D 环绕、超低音增强。一键预设：关 / 音乐 / 电影 / 夜间 / 耳机。默认全关且对声音零影响。

插入点两端一致：**在立体声展开之后、混响之前**。

### 14.2 免部署方案：一套可配置端点覆盖公网与局域网

**技术边界**：两台设备要汇合，必然需要一个双方都能到达的「汇合点」。完全零部署且跨公网，只能靠已有的公共基础设施；因此把汇合点做成**可配置端点**，而不是二选一：

| 端点模式 | 部署要求 | 网络范围 | 实现 |
|---|---|---|---|
| **公共中继（默认）** | 手机/电脑都零部署、零注册 | 跨公网、异地异网 | 公共 MQTT-over-WSS broker（EMQX / EMQX-CN / HiveMQ 自动 failover） |
| **局域网直连** | 电脑端内置服务零部署；手机填地址 | 同一 WiFi | Electron 主进程内置 WS 中继，数据不出内网 |
| **自建服务器** | 沿用原有 sync-server | 取决于服务器 | 原 `JamRoomClient` HTTP 轮询，**一行未动** |

**安全**：房间码不出现在中继上（频道名 = `SHA-256(房间码)` 派生），载荷用房间码派生密钥 **AES-GCM 加密 + 认证**，公共中继只能看到密文。安全边界如实说明：房间码仍是 6 位短码，与原有设计等同，保护的是「第三方抓包者看不到歌名/队列/进度」，不提供针对已知房间码的强机密性。

**无服务器下的房间语义**：房主是唯一发布者（沿用 `jamProtocol` 约定），1s 周期广播全量快照供后加入者对齐；客机广播 `hello` 心跳、房主维护成员表；房主退出广播 `bye` → 客机走既有 `closed` 清理路径。

### 15.6 已知说明（非缺陷）

- **未做代码签名**：Windows 安装包首次运行会触发 SmartScreen「未知发布者」，选「仍要运行」即可；Android 需允许「安装未知来源应用」。
- **MNN 原生推理**：exe 构建日志出现 `file source doesn't exist from=build/mnn/win-x64`，这是 `beforePack` 的预期分支 —— Windows 不捆绑 MNN runtime，节拍/分轨分析自动回退到估算器，不影响其他功能。
- **模型文件未打进源码包**：`models/`（约 127MB 的 `.bin` 权重）与 `release/`、`dist/` 属于构建产物/运行资产，不是源码；从零重建时按「十二」执行 `npm install` 后自行准备模型与 ffmpeg 资源即可，直接用 `安装包/` 里的成品则无需关心。
- **dist 当前是 Capacitor 版**：构建顺序为先 Electron 后 Android，工作区 `dist/` 最终停留的是 `FOLIA_BUILD_TARGET=capacitor` 产物；重新构建 exe 前需按「十二」重跑一次 `ELECTRON_DEV=false ELECTRON=true npx vite build`。
- **versionCode 未变**：仍是 `7025011`，旧版可直接覆盖安装，无需卸载。
