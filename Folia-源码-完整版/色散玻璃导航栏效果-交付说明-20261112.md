## 3. 算法原理（独立重写要点）

1. **位移图**：三段式线性渐变（暗→中性灰 128→亮）分别驱动 R（水平）与 B（垂直）通道，两层 `mix-blend-mode:difference` 混合后中心趋近中性、四周产生梯度；再覆盖一层模糊的中性圆角矩形，把折射收敛到边缘。SVG 以 `data:image/svg+xml,` 内联喂给 `<feImage>`。
2. **折射**：`feDisplacementMap` 用位移图的 R/B 通道决定像素位移，位移量 = `scale × (channel/255 − 0.5)`。三通道 scale 递减（150 / 138 / 126）制造折射差。
3. **色散**：三条通道各带不同 `feOffset`（由 `chromaticOffset` 归一化，默认 92 / 上限 140），经 `feColorMatrix` 只留单色后 `feBlend mode="screen"` 合成，得到彩色镶边。
4. **回位**：`baseShiftX ≈ −scale/2` 抵消整块位移，避免内容被推走；垂直色散 `verticalFactor=0.08` 压得很小，防文字上下抖动。

## 5. 如何接入真实导航位（下一步由你确认后动手）

本组件**目前是独立可挂载的，未改动 `AppShell` / `PanelShell` 任何 DOM**，避免你此前反复担心的代码冲突。接入示例：

```tsx
import { LiquidGlassNavBar } from '@/components/liquidGlass';

// 直接整栏替换（最快看到效果）
<LiquidGlassNavBar tone="dark" />
```

或把单个元素替换为玻璃原语：

```tsx
import LiquidGlass from '@/components/liquidGlass';

<LiquidGlass radius={28} interactive active={isActive}>
    <Icon size={18} /><span>首页</span>
</LiquidGlass>
```

建议挂接点（按风险从低到高）：
1. **底部播放控制条**（`floating-player`）—— 改动面最小、视觉收益最高；
2. **面板页签**（`PanelShell` tablist）—— 页签激活态的青绿描边很搭；
3. **左侧导航 rail / 顶栏账号胶囊** —— 全栏替换时用 `LiquidGlassNavBar` 整体替换。

> ⚠️ 接入前建议先在真机（Electron 43 / Chromium）上用演示页确认观感，再逐位替换；Firefox / Safari / 远程预览环境会自动退回普通磨砂，不会出现破图。
