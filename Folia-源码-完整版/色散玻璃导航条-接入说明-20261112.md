# 色散玻璃导航条 · 接入真实导航（2026-11-12，已支持毛玻璃⇄液体玻璃切换）

## 本次做了什么

把上一轮独立写好的「色散液态玻璃」组件，**以可开关、零回归的方式接入到项目真实的底部播放胶囊**（最接近 Mineradio 导航栏观感的常驻元素），而不是改 AppShell / PanelShell 的 DOM 以免引入冲突。

**11-12 更新**：原设计把色散玻璃「叠」在毛玻璃之上；按需求改为**两种质感互斥、可互相切换**——
设置里用分段控件（Segmented）在「毛玻璃」与「液体玻璃」之间切换，二者不会叠加，切换即生效。

> 背景：本组件视觉思路致谢 Mineradio 2.2.0（GPL-3.0-only）。本项目为 AGPL-3.0，条款不相容，因此**全程独立重写**，未复制任何 Mineradio 源码。

## 两种玻璃质感（互斥、可切换）

| 质感 | key | 观感 | 实现 |
| --- | --- | --- | --- |
| 毛玻璃（默认） | `frosted` | 半透明垫底 + 磨砂 | `backdrop-blur-xl` / `backdrop-blur-md` + 半透明 `bg` |
| 液体玻璃 | `liquid` | 边缘凸透镜折射 + 彩色镶边 | `folia-chromatic-glass` + 内联 `backdrop-filter: url(#id)`（SVG 色散滤镜） |

同一份 `playerBarGlass` 设置**同时驱动**底部播放胶囊与顶部标题栏背景，二者一起切换、互不叠加。

切换逻辑在 `FloatingPlayerControls.tsx`（胶囊）与 `AppShell.tsx`（标题栏背景 `motion.div`）上**二选一**：

```tsx
${playerBarGlass === 'liquid' ? ' folia-chromatic-glass' : ' backdrop-blur-xl'}
```

## 接入策略（最小侵入）

| 关注点 | 做法 |
| --- | --- |
| 不破坏结构 | 不动底部胶囊的 framer-motion `transform` / `layout` / 拖拽逻辑，只换 `backdrop-filter` 来源 |
| 零回归 | 新增设置项「底部播放条玻璃质感」，**默认毛玻璃**；选毛玻璃时 UI 与原版完全一致 |
| 自动降级 | Firefox / 非 Chromium 的 Safari 下液体玻璃自动退回普通磨砂；窗口/远程预览同样安全降级 |
| 不覆盖底色 | 液体玻璃的 `.folia-chromatic-glass` 只补内高光 + 青绿描边光晕，绝不动胶囊原有 `border` / `box-shadow` |

## 如何查看

1. 桌面端打开「设置 → 播放器 → 玻璃质感（播放条 / 顶栏）」；
2. 在「毛玻璃 / 液体玻璃」之间点选即可实时切换，**底部播放胶囊与顶部标题栏同时生效**：
   - 毛玻璃 = 默认半透明磨砂底；
   - 液体玻璃 = 边缘凸透镜折射 + 彩色镶边；
3. 切回毛玻璃即恢复原普通磨砂底，无任何残留。
