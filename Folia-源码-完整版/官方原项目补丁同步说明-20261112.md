## 2. 已打补丁

### P1　`f1a4069c` / #282 / #264　叠层动画周期回抽（本次核心）

**现象**：叠层每 3 秒核对显示状态时，读的是后台每秒采样的**缓存位置**；现场日志约每 3 秒一次 `lyrics anchor jumped`，幅度 **-600 ~ -1100 ms**，歌词和主题内容明明没变却发生位置回退与可视化重建。这与你反复提到的「过渡结束后位置又往下走一段」属于同一类根因（陈旧锚点覆盖了新位置）。

| 文件 | 改动 |
| --- | --- |
| `player/DisplayAnchorGeneration.kt` | **新增**。epoch / pending 世代保护：控制命令照原队列执行，只让跨越控制动作的旧采样失效 |
| `player/FoliaNativePlayer.kt` | 加 `displayAnchorGeneration` 字段；`prepare` / `seek` / `crossfadeTo` 入口 `begin()`，`runOnPlayer` 包 `try/finally` 配对 `finish()`；`release()` 里 `close()`；新增 `sampleDisplayAnchor()` 在播放器线程读 `current.currentPosition` |
| `player/FoliaNativePlayerPlugin.kt` | `player` 加 `@Volatile`；`refreshDisplayAnchor()` 由「读 `mediaSnapshot()` 缓存」改为 `current.sampleDisplayAnchor { … }`，并二次校验 instance / player 未被替换 |
| `entries/wallpaperSurfaceContent.ts` | **新增**。`reuseWallpaperContent()` 深比较 theme / lines，内容不变时复用旧引用 |
| `entries/wallpaperSurfaceBridge.ts` | `__foliaWallpaperPush` 入口接上引用复用，避免时间包经 JSON 解码触发可视化重建 |
| 4 个回归单测 | 新增，见第 4 节 |

> 官方刻意守住的边界全部保留：原有 **250 ms 容差不变**、不禁止合法 seek、不丢弃任何控制命令。没有靠调大容差或删装饰来「掩盖」卡顿。

### P2　`13e2efdc` / #263　暂停当场生效（原生侧）

本地 `pause()` 把 `setPlayWhenReady(false)` 放在淡出完成回调里。淡出那 160 ms（混响留尾巴时最长 1.2 s）里任何一次 `play()`（通知栏补发、回前台补发、部分 ROM 同一手势派两次）都会先恢复播放，再在 `rampVolume` 里 `cancelFade()` 把淡出连同回调一起撤掉 —— 结果是**按了暂停、约 1 秒后自己又响起来**。

改动 `FoliaNativePlayer.kt`：暂停**当场** `setPlayWhenReady(false)`；新增 `rampVolumeHold()` 只滑音量、不碰 `playWhenReady`；淡出收尾用 `if (!cachedPlaying)` 保护音量复位。

### P3　`39bd13ea` / #1042　置顶窗口吞掉桌面点击

官方注释直接点名 "an always-on-top overlay would swallow every click"：Raw Input 早于点击激活到达，从别的窗口点到桌面时前台仍是那个窗口，按下门控 `is_desktop_foreground()` 会把这一下吞掉；**常驻置顶窗口（正是你的 Windows 桌宠）会让每一次桌面点击都失效**。

改动 `packaging/windows/wallpaper-helper/src/mouse_forward.rs`：按下只判「光标下的顶层窗口是不是桌面」，移除前台判定；`events.rs` 同步注释。**move 与滚轮的前台条件保持不动**（官方明确要求，#717 的保护靠「按下要求光标下是桌面」这一条）。

## 6. 风险与真机待验

- 沙箱没有 Android GUI 与真机 WebView：**叠层回抽是否消失、暂停是否不再自恢复、桌面点击是否可穿透**，这三项只能实机确认；本次保证的是编译通过与源码契约。
- P1 修的是**歌词 / 可视化叠层的位置采样链路**，与 `FloatingWhaleService.kt` 的鲸鱼几何过渡是同类根因（陈旧锚点）但**不是同一段代码**。鲸鱼落点 / 下移问题不会因本补丁自动解决；若要根治，需照同样的「实时采样 + 世代保护」思路改鲸鱼窗口的落点读取。
- 你的 Windows 桌宠用 `alwaysOnTop('screen-saver')`，P3 正是针对这种常驻置顶窗口；但 helper 要重新编译（`npm run build:wallpaper-helper`）才会进新的 exe。
- 本次**未重新打包** exe / apk / 源码 zip。若要出新包，需先 `cap:sync:android` + `vite build`，再分别走 Electron 与 Android 构建；两端 `dist/` 互斥的约束不变。
