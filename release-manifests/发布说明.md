## v0.7.41 · 播放稳定性与更新链路加固

- **播放与歌词**：修掉切歌后被丢弃的在线音源请求仍写入缓存、同曲快速重播时旧歌词覆写新歌词；Worker 加 4 秒超时与主线程兜底，扫码/解析不再因为 Worker 加载失败永久卡住；播放缓存写入串行化，避免恢复出「歌 B + 队列 A」的错配；原生切歌在回退 Web 前二次确认引擎快照，减少双音源。
- **B站**：首页七模块分页真正前进（原来一直重复第一页）；收藏夹两层结构可进入；风控码按「稍后再试」退避；单条脏数据不再拖垮整模块；`buvid3` 兼顾 Android 原生桥的镜像响应头。
- **登录与会话**：首页隐藏时不再停掉登录会话，扫码窗口照常可用；Grid 页签循环键改 F6，不再抢键盘用户的 Tab。
- **更新链路**：版本清单解析兼容 BOM/缩进/注释；下载完成后状态正确推进到「重启安装」；镜像返回的清单若把安装包指向非 GitHub 域会被拒绝；beta/alpha 模板不再复用正式包地址与摘要。
- **工程**：codemap 分层边界进 CI 门禁；鸿蒙 Release 的 tag 触发与上传路径修正；安装器跨模式检测给出可见提示。

逐项记录见仓库 CHANGELOG.md 与 `改动清单与待办-2026-11-24.md`。
